WorKey 진척도 대시보드

새 기능 추가

사용법: 카드 클릭 = 세부사항 모달. 카드의 상태 뱃지 클릭 = 상태 순환 (미완료 - 진행중 - 완료). 상태 변경은 모달 안 버튼으로도 가능.
모달에서 의존성 ID 클릭 = 해당 항목으로 이동. 항목별 개인 메모 작성 가능. 변경 이력 버튼 = 상태 변경 기록 조회.
상태·메모·이력은 브라우저 localStorage에 자동 저장. JSON 내보내기로 백업 가능.
SSOT(WorKey - 전체 진척도.md) 갱신 후 python3 dashboard/generate_seed.py 실행하면 이 파일의 시드가 갱신됨. 시드 갱신 후 내 로컬 상태와 SSOT가 다른 항목엔 "SSOT 불일치" 뱃지가 뜨고, 뱃지 클릭으로 SSOT 값을 수용할 수 있음.
